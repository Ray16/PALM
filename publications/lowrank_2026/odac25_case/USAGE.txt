ODAC25 Filtered: metadata-only composition split
================================================

Sources and downloads
---------------------
PROVENANCE.json is the source and transfer ledger. It records:
  * The official ODAC25 DATASET.md URL and pinned revision, with a local copy.
  * The pinned ColabFit Train_Filtered and Val_Filtered repository revisions.
  * Every source Parquet URL, source size, selected columns, transferred bytes,
    HTTP range request count, compact cache SHA256 and cache-write timestamp.
  * The extraction scripts and their checksums.

Only names, chemical_formula_hill and multiplicity were selected. Parquet
footers and selected column chunks were fetched using HTTP byte-range requests.
The reader refuses non-206 responses and incorrect Content-Range headers before
reading the response body. Complete shards/archives, atomic coordinates, forces
and energy labels were not downloaded.

Successful production reads transferred 63,431,987 bytes. A separate recorded
probe transferred 248,514 bytes; a preliminary failed projected-column probe and
small documentation/API requests were not fully metered. The production number
must not be described as an exact whole-session transfer count. Expanded compact
JSON caches occupy about 1.2 GiB locally; that is not the network transfer size.

Coverage
--------
All 82 configuration shards in the pinned ColabFit filtered repositories are
covered. The mirror stores 37,456,852 configuration rows. Its multiplicities sum
to exactly the official filtered counts:
  Original training:   36,920,036
  Original validation:    791,638
  Total:               37,711,674
This is an aggregate coverage reconciliation, not a row-by-row comparison with
the original ASE-LMDB archives or a certification of identical energy labels.
Both original partitions are pooled and newly assigned. The official partition
is retained in configuration_counts.csv, not silently treated as the new test.

Split definition
----------------
Results: splits/Filtered/seed0/

1. Infer conservative framework families from source trajectory names:
   strip adsorption/GCMC suffixes; group Gen<number> trajectories together;
   group six-letter CSD parents including polymorph, defect and functionalization
   suffixes. Keep other source-name prefixes. These are inferred family keys,
   not the official mof_name field, which the mirror does not retain.
2. Form immutable connected components linking shared configuration aliases,
   inferred family identity, identical reduced observed composition, and known
   identical reduced bare-host composition. Groups are never dissolved.
3. Use the 118 elemental atom fractions of each observed full-system composition.
   Average equally over distinct reduced observed compositions within each group.
   No energy labels or model outcomes select the assignments.
4. Run plain low rank on those group representatives with standardized Euclidean
   similarity 1/(1+distance), rank 256, four restarts, 25 iterations, refinement,
   seed 0, and exact 80/10/10 capacities BY INDEPENDENT GROUP COUNT.
5. Propagate each group's assignment to all its source configurations.

There are 2,913 inferred families, 205,269 distinct observed reduced formulas,
and 2,050 independent components. Group counts are 1,640 train / 205 val / 205 test.
Frame counts differ because families have different numbers of configurations:
  Train: 29,717,477
  Val:    2,278,663
  Test:   5,715,534
These counts include source multiplicities. Do not call these 80/10/10 frame counts.

Known bare formulas are obtained from bare-MOF rows or explicit single/mixed-
adsorbate subtraction. Subtraction matches 97,870 corresponding bare trajectories
with zero mismatches. It recovers compositions for 423 additional inferred
families; 92 families remain without bare formulas. Their missing bare formulas
are not guessed. Every group's feature vector consistently uses OBSERVED
FULL-SYSTEM composition, including adsorbates. The known-host links strengthen
grouping but do not establish complete structural or topology independence.

Applying the split
------------------
The small family_assignments.csv maps inferred families to folds; the larger
formula_assignments.csv maps observed reduced formulas to folds. For original
trajectory metadata, lookup.py applies exactly the saved name rule:

  /nfs/lambda_stor_01/homes/rzhu/miniforge3/envs/palm/bin/python \
    odac25_metadata/lookup.py --partition mof_plus_adsorbate \
    --name RACZIG_0.08_0_w_H2O_3

In Python (with odac25_metadata on sys.path):
  from lookup import SplitLookup
  fold = SplitLookup()(atoms.info['name'], partition='mof_plus_adsorbate')

Unknown families raise an error. For another release/revision, verify catalogue
coverage before applying the map. No coordinate download is needed to read or
use these assignment tables.

Validation and interpretation
-----------------------------
summary.json reports capacities, counts, timings, method hashes and sampled
group-level similarity diagnostics. independent_audit.json checks every compact
source record against the saved family/formula assignments and count totals.
Eight unit tests cover formula invariance, names, adsorbate subtraction, aliases,
rare-element fractions and refusal of whole-file HTTP responses.

The measured split call takes about 5.5 CPU seconds for 2,050 representatives.
This is NOT a benchmark of optimizing 37.7 million independent points. It excludes
network extraction, metadata aggregation, feature construction and diagnostics.
The original network extraction was not timed end-to-end with a dedicated timer.
Do not infer a same-hardware speedup over other splitters from this application.

The sampled group-kernel cross-fold share is 0.1711 (low rank) vs 0.3408 (matched-
count random); nearest-training similarity is 0.2459 vs 0.5073. These evaluate
group-average composition vectors, not individual atomic environments or physical
prediction accuracy. This is a composition generalization test, not evidence of
crystal-topology novelty or prospective deployment performance.

Reproduction
------------
Use the recorded palm Python environment and hide CUDA; no GPU or fleet needed.

  export CUDA_VISIBLE_DEVICES=''
  export OMP_NUM_THREADS=2 MKL_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2
  task_python=/nfs/lambda_stor_01/homes/rzhu/miniforge3/envs/palm/bin/python
  "$task_python" odac25_metadata/collect.py --release Filtered
  "$task_python" odac25_metadata/build_split.py --release Filtered --seed 0
  "$task_python" odac25_metadata/audit.py
  "$task_python" odac25_metadata/provenance.py
  "$task_python" -m unittest discover -s odac25_metadata -p 'test_*.py' -v

collect.py resumes from compact caches. With caches and manifests present,
build_split.py and audit.py operate entirely offline. Source data remain CC-BY-4.0;
cite ODAC25 and identify the ColabFit conversion and pinned revisions.
