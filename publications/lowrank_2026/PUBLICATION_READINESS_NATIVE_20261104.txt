Publication readiness after metadata-only native-split extension
=================================================================

Technical revision completed 4 November 2026
-------------------------------------------
Title: Scalable Dataset Splitting through Constrained Low-Rank Similarity Optimization.
The original 540-case controlled-optimization package remains intact. The native
extension adds 30 completed fresh-process cases with no production budget failures
on PCQM4Mv2, MOSES and ogbg-molpcba. Both grids preserve their actual source
versions, settings, hardware, input identities and outcome inventories.

Only 90,293,593 metered dataset-payload bytes (90.3 MB) were retrieved for the
three large native-split collections. No coordinates, SDFs, trajectories,
processed graph arrays or model weights were downloaded. The tally excludes
small discovery pages/JSON and HTTP headers, as explicitly documented. Packed
fingerprints are generated locally and are not redistributed as bulk caches.

Original and retained populations
---------------------------------
PCQM4Mv2: 3,746,620 original records; 3,746,581 retained after 39 RDKit parse failures.
MOSES: 1,936,962 records, all retained.
Ogbg-molpcba: 437,929 original records; 437,927 retained after two parse failures.
Every method uses the same retained rows. Native roles, identities, source hashes
and parsing losses are recorded. Chemical duplicates are audited and retained.
Fingerprint identity is not asserted to mean identical chemical graphs/geometries.

New measured result (means of three seeds, 16 CPU cores)
-------------------------------------------------------
Exact-count assignment-only low rank takes 304.0 s / 55.4 GiB peak RSS on PCQM4Mv2,
186.0 s / 28.9 GiB on MOSES and 40.6 s / 7.0 GiB on ogbg-molpcba. Native versus
low-rank global scores are 0.978 vs 0.620, 1.000 vs 0.784, and 0.963 vs 0.781.
Native versus low-rank aggregate held-out nearest-training means are 0.710 vs
0.537, 0.723 vs 0.605, and 0.651 vs 0.570. All quality values use the original
Tanimoto, independently of the factorized objective. Per-role values and sampling
intervals remain separate from seed variation.

Generation time includes the public numerical call. Loading, unpacking, input
adapter, warm-up and independent auditing are outside the clock. Native original
construction times were not supplied; assignment loading is never called an
alternative optimization runtime. Peak RSS precedes auditing and includes inputs.
The standard 1% corridor setting is separately reported. Exact assignment explicitly
disables refinement; the unchanged default skips point refinement above two million.

Interpretation and limitations
-------------------------------
The native datasets define CID/scaffold/generation-specific tasks. Count matching
or a 1% corridor does not preserve every native chemical grouping constraint.
These are structural/cost experiments, not isolated native optimizer comparisons
or evidence of better deployment prediction. PCQM4Mv2's four released roles are
preserved using a validated specification adapter to unchanged k-way numerical
functions. Blind test responses remain unavailable, so repartitioning all PCQM4Mv2
records does not immediately create a fully labelled prediction benchmark.

The six-dataset direct dense controls remain the central algorithm comparison.
The new returned-cut audits also show why error relative to a small cut matters:
PCQM4Mv2 rank-256 cut-relative point errors reach about 3.50%, despite only about
0.40% error relative to total kernel mass. These are sampled fixed-partition
diagnostics with approximate Monte Carlo intervals, not optimizer certificates.

Verification and reproducibility
---------------------------------
The earlier package has 226 passing regressions and 810 independent assignment
replays. The native extension has five additional regression tests, complete
assignment/count/query/metric/interval replay, 3,072 independent RDKit pair checks,
168 NumPy query checks against complete training folds, and 18 returned-cut
fidelity audits. A reconstruction regression checks the saved-landmark audit.
Pinned input reconstruction verifies all nine metadata objects without redownloading.
The main/SI build enforces source, artifact, numerical, reference, font and reviewed-
render checks; a fresh relocated build is required for final delivery.

The main paper follows formulation, accuracy/optimization, scale, and matched/native
benchmarking; detailed grids stay in the supplement. Counts, constraints, timing
scopes, role meanings and uncertainty are stated alongside the results.

----------------------------------------------
Author contributions, funding, competing interests, venue choice and final author
