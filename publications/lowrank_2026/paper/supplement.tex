\section{Current-version evidence and provenance}

The primary article describes v0.2.0.dev3, with numerical package source pinned
to commit \texttt{f7e0866}. The 199-case primary grid yields 191 successful
numerical cases and eight native DataSAIL configurations reporting infeasibility.
The v1 benchmark adapter subsequently raised an exception when reading those
absent native assignments; their solver evidence is preserved and no score is
imputed. A separate 72-case publication check uses structured infeasibility
outcomes, equal-confidence accuracy controls and native-memory profiles.
Full-kernel fidelity supplies 900 comparisons over six datasets, three seeds,
two powers, five landmark counts and five partitions.

Every successful case retains its source/input manifest and assignment checksums.
Independent full NumPy Tanimoto calculations check 246 saved global and local
scores, including all group controls and current external-method comparisons.
The package suite passes 223 tests. These checks establish implementation and
artifact consistency; they do not certify an optimizer or a deployment boundary.

FreeSolv, ESOL, BACE, BBBP, Lipophilicity and Tox21 are full public datasets with
all successfully featurized entities retained. QM8 additionally tests audit
budgets. These datasets have informed development and are not described as
permanent holdouts. Optimization uses feature values and declared constraints,
never model test outcomes. Exact input identities and feature counts are
recorded in the manifests.

Original thresholded and alternative-fingerprint outputs remain in the
per-case records. Raw mean nearest similarity was selected for the current
presentation during revision to keep an interpretable common scale.
This presentation choice did not change the fixed method settings or model
recipes. The analyses are descriptive development studies, not preregistered
confirmatory evaluations.

\section{Factor construction, optimizer and feasibility contracts}

The landmark matrix is diagonalized in float64. Eigenvalues at or below a
relative threshold of the largest eigenvalue are discarded rather than floored;
the default relative tolerance is $10^{-8}$ with a numerical-size safeguard.
The effective factor dimension can therefore be smaller than the requested
landmark count. Entity--landmark products are row blocked.

The similarity-spreading landmark heuristic, historically named
\texttt{kmeans++}, samples distinct eligible rows with weights proportional to
$(1-\max_j S_{ij})^2$, falling back to uniform unselected rows when all residual
weights vanish. It is not ordinary squared Hilbert-distance sampling.
Ordinary k-means++ guarantees are not claimed for this rule. Uniform landmark
sampling remains available. Established work discusses alternative sampling
strategies \citep{kumar2012,musco2017}.

For nonnegative requested fractions $q_c$ summing to one, largest-remainder
rounding gives targets summing to $n$. The tolerance corridor is formed from
$(1\pm\epsilon)nq_c$, with integer bounds widened only enough to contain the
rounded target. For point-level assignments, the two-fold linear proposal sorts
preference differences within both folds' bounds. More than two folds use a
regret-ordered capacity peel. An actual factor-objective check rejects worsening
proposals. The best unrefined candidate is retained while two candidates are
refined before final selection. Exact capacities use count-preserving swaps;
corridors permit legal single moves. The final objective guard can reject
numerically worsening refinement. Point refinement is skipped above two million
entities. These are heuristic choices, not convergence or global optimality
certificates.

The standard combined pipeline also offers the pointwise solution as a
grouped warm start. The controlled same-group study instead supplies the same
seeded feasible group packing to both power settings. Packing preferences are
independent of factor values. Exact-capacity feasibility can use a bounded
integer-program fallback. An independently checked integer incumbent is accepted;
a proved infeasible result and a timeout without a valid incumbent are reported
separately. The strict policy never dissolves a group. The count-first policy
may dissolve groups to meet counts, and records those relaxations.

Optional fold-pair weights enter factor optimization and weighted scoring
consistently. All primary comparisons use equal weights on distinct fold pairs.
The n-D software path uses sparse identity factors and record-weighted feature
preparation; these features are tested software capabilities outside the primary
molecular comparison. Their API and memory scopes are documented with the
package.

\section{Exact-reference decomposition and matched-group controls}

The small reference suite contains twenty binary $12\times24$ matrices drawn
with Bernoulli probability 0.3 at fixed seeds. Counts are 8/2/2, not the larger
datasets' 80/10/10 proportions. Enumerating 2,970 unrestricted assignments or
thirty assignments of six paired groups gives exact minima for both the full
and approximate kernels. For each returned partition, the records retain
heuristic suboptimality for the approximate kernel, the largest approximation
error over the feasible set, and suboptimality for the full kernel.
These finite enumerations do not certify larger problems.

\section{Accuracy allocation and uncertainty}

The cut audit samples a signed residual mean, takes its absolute value, and
normalizes by mean absolute off-diagonal kernel mass. This is cut error for
the specified partition, not entrywise mean absolute error or error relative to
the cut itself. Bounded empirical-Bernstein intervals cover numerator and
denominator components jointly \citep{maurer2009empirical}.
The two-sided mean radius for samples in $[a,b]$ is
\[
 \sqrt{\frac{2\widehat v\log(4/\alpha)}{m}}
 +\frac{7(b-a)\log(4/\alpha)}{3(m-1)},
\]
with unbiased sample variance $\widehat v$, sample count $m\ge2$ and component
failure budget $\alpha$. It applies the cited one-sided bound to both tails
after range scaling. Analytically zero contributions can be excluded;
sampled zero mass alone never establishes an empty or accurate factor.
A denominator interval containing zero gives an unestablished result.
Known-small populations are enumerated exactly.

For the optional joint rank/probe policy, a finite doubling grid defines at most
$R Q$ possible checks. Each selection check spends failure probability
$0.025/(RQ)$, and a separately sampled final audit spends 0.025.
The union bound does not require independence between selection checks.
A candidate partition at a fixed rank is computed without using the audit pairs.
When an interval straddles tolerance, probe count grows first; when error is
established or probes reach their limit, rank grows if possible. The reached
probe count carries forward. All pair evaluations, including repeated checks,
are counted. The historical diagnostic key \texttt{ci95} contains the interval
at its accompanying reported confidence, which can exceed 95 percent.

Fixed-probe controls use the same joint-valid policy with equal initial and
maximum probe counts. This avoids comparing policies with different overall
confidence budgets. Selection and final auditing must both establish tolerance;
exhaustion remains visible even when the point estimate looks favorable.
The older fixed-probe experiment, whose two stages separately used 95 percent
coverage, remains in its original records but supplies no equal-confidence
efficiency claim.

\section{Native baseline constraints and resource profiles}

DataSAIL's native group mapping is observed immediately before its unchanged
solver call, after its own overflow handling. Both matched controls preserve
all rows and exact native counts; one also preserves every observed group.
This does not equate linked cluster similarities with sums of entity-level
similarities. Reported native infeasibility concerns the declared clustering,
capacity and solver configuration, not DataSAIL's ability to process the dataset
under every possible setting.

Ordinary graph construction forms the union of positive top-k pairwise
similarities, with one undirected edge per unordered pair. Integer scaling
respects a conservative 32-bit accumulation budget, and any count repair uses
the same integer-weight graph. Native integer cuts are independently checked
against edge sums. Both native and repaired partitions are saved.

The primary grid times complete native split calls with two pinned cores.

before the first scoring call; DataSAIL's later matched controls cannot inflate
its reported native memory. This scope includes input arrays, imports and the
common small low-rank warm-up. Different time-limited native solves can return
different assignments; each profile retains its own outputs.

\section{Scaling, quality audits and censored outcomes}

The current CPU protocol uses nested ChEMBL samples, 2048-bit fingerprints,
rank 256, four restarts, two refined candidates, and exact or 1 percent
capacity corridors. The plain setting is attempted through two million entities.
The exact-neighbour combined CPU setting has a separate 10,000-entity range.
Each timed split follows a 100-entity warm-up. A 1,800-second end-to-end case
budget includes loading and independent audits; its expiration does not imply
that the split call alone consumed that time. Partial outputs and terminal
failure records remain preserved.

For completed calls, the deterministic factor is reconstructed outside the
split clock and its landmark indices and factor objective checked against the
public split diagnostics. Independent pair samples evaluate the returned cut.
Up to 128 uniform test queries are compared with the complete training fold.
The nearest-similarity mean uses a conservative bounded-mean sampling interval.
Input arrays and framework overhead are included in process RSS; peak RSS
immediately after splitting is distinguished from the later process peak.

Earlier-release H100 timings appear only in the archival section. They are not

The separate largest-scale current-code protocol runs on lambda13 with two
disjoint 32-core CPU allocations and hidden CUDA devices. Three two-million-entity
plain cases use the same default numerical package and a 1 percent corridor.
Packed inputs are prepared once in an immutable node-local cache. A completed
timed split is persisted before a separate independent-audit phase, so an
interrupted audit need not repeat optimization. The phase budget is 3,600 seconds.
All three splits and their audits complete. Their timings are not placed on the
two-core curve or used to infer an algorithmic speedup between hosts.

\section{Synthetic independent-cohort protocol}

Each generated instance contains fifty observed families with forty entities
each, four Gaussian stable features, Gaussian family effects with standard
deviation two, and observation noise with standard deviation 0.25. The stable
response is $2z_1-z_2+0.5z_3$. Full features concatenate a fixed 100-family
one-hot universe with $0.05(\operatorname{clip}(z,-4,4)+4)$.
Only the first fifty families occur in the split pool. Known-family and
new-family evaluation observations use independent random draws; the latter
use the remaining fifty independent family effects. A declared shared universe
of identity features supplies no response information about unseen families.

The invariant ridge reference receives the unmodified stable features and uses
penalty one. Five-neighbour regression uses the full representation. Both
recipes are fixed. The invariant reference's access to generative features
is privileged and is part of the mechanism design, not an asserted real-data
feature-selection ability. The plain cosine case uses an exact finite feature
map when available, while powering uses Nystr\"om features. The family-reference
split assigns entire generator families and has the same 1600/200/200 counts.
Labels never enter structural split construction.

For each trained model, interpolation risk is evaluated on independently drawn
observations from families present in that model's training fold. New-family
risk uses the same independent unseen-family cohort for all policies within an
instance. Different splits consequently need not share an identical interpolation
cohort. The target is the declared conditional transfer task, not an unconditional
comparison of model accuracy between split policies. Twenty seeds define twenty
independent generated instances. Per-instance results, ranking comparisons and
assignment hashes are retained.
